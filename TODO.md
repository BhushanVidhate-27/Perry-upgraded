## How it runs

`next start` is the server. Next's `instrumentation.ts` starts Perry's backend
(`server/index.ts`) in the same process: one SQLite file, the functions in
`convex/`, the scheduler, and Telegram long-polling. The dashboard and
`/api/backend/*` are the same process, so one instance serves both.

Node 22 is required (`node:sqlite`); the Dockerfile uses `node:22-alpine`.

## What is configured

| Env var | Value |
|---|---|
| `NODE_ENV` | `production` |
| `PORT`, `PERRY_PORT` | `7377` |
| `PERRY_HOME` | `/tmp/perry` (free plan has no disk) |
| `PERRY_EMBEDDING` | `off` (512 MB cannot hold the model; search falls back to words) |
| `DASHBOARD_KEY` | generated by Render |

## What is missing

Set these in the Render dashboard (Environment) and redeploy:

- `TELEGRAM_BOT_TOKEN` — from @BotFather. Without it Perry idles; the dashboard still works.
- `B2_KEY_ID`, `B2_APPLICATION_KEY`, `B2_BUCKET_NAME` — optional; without them files stay on the instance.
- `PERRY_PASSWORD` — optional. Until it is set (env, or `/password set` in Telegram) the dashboard is open to anyone with the URL.

## Password

`/password set <pw>`, `/password reset`, `/password status` in Telegram write
`$PERRY_HOME/dashboard-password`; `proxy.ts` (Next 16's name for middleware)
reads it on every request and redirects to `/login` without a `perry_session`
cookie. `PERRY_PASSWORD`, if set, wins over the file. The login API sets the
cookie (30 days, httpOnly).

## Free-plan limits (why Starter is the real home)

- No disk: SQLite, chats, notes, secrets live in `/tmp` and are lost on every
  deploy/restart. Env vars survive.
- The instance sleeps after 15 minutes without inbound HTTP. Telegram polling
  is outbound, so the bot stops until something pings the URL; a cron ping
  every 10 minutes keeps it awake.
- 512 MB: the local embedding model is off (`PERRY_EMBEDDING=off`).

Starter ($7/mo) + a 10 GB disk (~$2.50/mo) makes it always-on and durable:
set `PERRY_HOME=/data/.perry`, mount the disk at `/data`, and drop
`PERRY_EMBEDDING` on a 2 GB plan.
